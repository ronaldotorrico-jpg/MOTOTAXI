# 🏍️ MotoRapido — Actividad #2

Página web interactiva para un servicio de moto taxi, desarrollada en equipo usando GitHub.

## Estructura del proyecto

```
mototaxi-motorapido/
├── index.html   ← HTML (3 participantes)
├── styles.css   ← Estilos CSS (3 participantes)
├── Python.py    ← Backend Flask + SQLite (3 participantes)
└── README.md
```

## División por participante

| Archivo      | Líder                        | Colaborador 1                          | Colaborador 2                   |
|--------------|------------------------------|----------------------------------------|---------------------------------|
| `index.html` | `<header>` logo, menú, banner | `<main>` servicios, tarifas, formulario | `<footer>` contacto, redes     |
| `styles.css` | Variables, reset, navbar, banner | Tarjetas, tabla, formulario          | Footer completo                 |
| `Python.py`  | Config, base de datos, ruta `/` | `/reservar`, `/tarifas`, `/estadisticas` | `/contacto`, `/exportar`, `/admin` |
